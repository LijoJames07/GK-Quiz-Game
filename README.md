# GK-Quiz-Game
A console-based General Knowledge Quiz Application built using Python. This project allows users to answer multiple-choice questions, validates user input, calculates scores, and displays performance at the end of the quiz.

---

## Features

- Multiple-choice quiz system
- Randomized question order
- Input validation
- Score tracking
- Percentage calculation
- Performance feedback system
